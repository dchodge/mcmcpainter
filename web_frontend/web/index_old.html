Technical Details

Temperature Schedule (Beta)

Controls the acceptance probability of MCMC moves. Starts at β_init (conservative) and gradually increases to β_final (more exploratory). Higher β values accept more moves, including those that temporarily worsen the image.

K Lambda (Line Count Prior)

Expected number of lines in the final painting. Acts as a regularization parameter - too low results in underfitting, too high in overfitting. Auto-setting uses 0.5 × canvas width as a heuristic.

MCMC Moves

Birth (25%): Add new lines in high-error regions
Death (25%): Remove existing lines
Jitter (45%): Perturb line parameters (position, color, opacity)
Swap (5%): Reorder line rendering for better composition

Performance Tips

• Higher iterations = better quality but longer runtime
• Larger dimensions = more detail but slower processing
• Lower β_init = more conservative early exploration
• Higher β_final = more aggressive final optimization
